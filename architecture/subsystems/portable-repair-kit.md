**Why I'm Building This**
Traditional repair workflows rely on USB sticks, external HDDs, or outdated CD/DVD media. These methods are slow, unreliable, and often fail in the field due to:
- USB drives getting lost or corrupted  
- External HDDs disconnecting randomly  
- Laptops/desktops no longer having CD drives  
- IoT devices and home routers failing to serve files consistently  
- Needing multiple tools for different OS types  

This project solves all of that by creating a simple, portable, offline server with easy FTP access.  
It provides a consistent, always‑available toolkit for helping people with IT issues on Windows, macOS, and Linux — without fumbling with cables, adapters, or unreliable storage devices.  
The goal is to make repairs faster, cleaner, and more reliable for friends, family, and anyone who needs help.

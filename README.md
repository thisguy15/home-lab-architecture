# 🏠 Home‑Lab Architecture

## Overview
This repository documents my personal home‑lab environment. It includes the systems, services, and networking setup I use for storage, remote access, media, automation, and family‑centric infrastructure. This is where I build real hands‑on IT experience through practical projects.

## Current Components
- TrueNAS Scale (storage + services)
- Plex media server
- Syncthing + Immich
- Raspberry Pi devices
- Tailscale mesh networking
- Remote access (SSH + RDP)
- Family privacy and reliability design

## What This Repo Covers
- Architecture diagrams
- System descriptions
- Networking layout
- Troubleshooting notes
- Future improvements

## Purpose
To document my real‑world IT experience as I transition into the field, and to show how I design, maintain, and troubleshoot practical systems.
